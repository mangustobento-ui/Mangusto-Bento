Base principal

Último backup

O sistema usa IndexedDB como banco de dados principal, adequado para muitos registos. O backup em JSON é uma cópia independente que podes guardar no PC, disco externo, OneDrive, Google Drive ou outro local. O backup automático para uma pasta requer permissão do navegador.

Zona de manutenção

Antes de apagar os dados, faça um backup. Não há cálculo de IVA nesta versão, conforme definido para este projeto.
